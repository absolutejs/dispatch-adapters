# Changelog

## 0.2.0 — 2026-08-01

- Require the unified Dispatch 0.7 contract.
- Map portable badges, sounds, actions, and deep links into APNs payloads.

## 0.1.0 — 2026-08-01

- Align the adapter and manifest with the current Dispatch 0.6 contract.
- Publish the first stable push-adapter release with an explicit Apache-2.0
  license artifact.

## 0.0.1

- Add APNs HTTP/2 delivery with pooled sessions.
- Add ES256 provider-token generation and fifty-minute rotation.
- Support alert/background headers, standard APS options, payload bounds, and
  normalized provider errors.
